# Gavel — Online Auction Platform (estate and equipment)

Build Log #17 (main track). Timed online auctions for a fictional regional house: proxy (max) bidding with the increment table as data, soft-close anti-sniping on an injected clock with a hard cap, every bid judged under one row lock and recorded in an append-only ledger whether accepted or rejected, idempotent submission, and settlement (winner, second price plus increment, buyer's premium in integer cents) as a pure function the verifier recomputes from the ledger. The thing this project exists to practise: many writers fighting over one row in the final seconds, proven by a deterministic barrier test and measured by a load script that prints its hardware.

## ⚠️ Scope Honesty (read first)

Learning project, synthetic data only. Every auction house, estate, lot, bidder and bid is generated by `tools/build_fixtures.py` from a seed; names come from fixed lists and emails use `example.com`. No real sale, consignor, buyer or money. Nothing is paid: settlement produces a mock invoice and stops. The bid rules (increments, proxy bidding, soft close) are one house's conventions written down as data, not an industry standard, and no claim is made about any state's auction law. Contention numbers (bids per second, latency percentiles) are measured on named hardware by a script in this repo and are not a capacity claim; a number without its hardware and its command is a guess. Banner verbatim in the README.
